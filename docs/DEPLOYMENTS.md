# Deployments

The live addresses are exposed by the application instead of copied into this file where they can become stale.

- Product: [rendasignal.xyz](https://rendasignal.xyz)
- Public proof: [rendasignal.xyz/proof](https://rendasignal.xyz/proof)
- Polygon configuration: [rendasignal.xyz/api/polygon/config](https://rendasignal.xyz/api/polygon/config)
- Public proof data: [rendasignal.xyz/api/proof](https://rendasignal.xyz/api/proof)

The current escrow contract version is set with `ESCROW_CONTRACT_VERSION`. Version 2 adds two-party, full-refund cancellation and must be deployed before the matching frontend is published.
